# 📰 RSS-читалка для Telegram

Telegram-бот для чтения RSS-лент с автоматической проверкой новых статей и функцией "Прочитать позже".

## ✨ Возможности

- 📥 **Подписка на RSS-ленты** - добавление и управление подписками
- 🔔 **Автоматические уведомления** - получение новых статей каждые 10 минут
- 💾 **Список "Прочитать позже"** - сохранение интересных статей для чтения позже
- 📋 **Управление подписками** - просмотр и управление вашими RSS-лентами
- 🗄️ **База данных SQLite** - надежное хранение данных

## 🚀 Быстрый старт

### Локальная установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <your-repo-url>
   cd RSS-читалка
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env` и добавьте токен бота:**
   ```bash
   cp .env.example .env
   ```
   
   Отредактируйте `.env` и добавьте ваш токен:
   ```
   BOT_TOKEN=your_bot_token_here
   ```

4. **Получите токен бота:**
   - Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Скопируйте полученный токен в файл `.env`

5. **Запустите бота:**
   ```bash
   python main.py
   ```

## 📦 Развертывание на Railway

Railway - это платформа для развертывания приложений, которая поддерживает Python и автоматически управляет базами данных.

### Шаг 1: Подготовка проекта

Убедитесь, что в проекте есть следующие файлы:
- ✅ `main.py` - основной файл бота
- ✅ `requirements.txt` - зависимости Python
- ✅ `runtime.txt` - версия Python (уже есть)
- ✅ `Procfile` - команда запуска (уже создан)
- ✅ `.env.example` - пример переменных окружения (уже создан)

### Шаг 2: Создание аккаунта на Railway

1. Перейдите на [railway.app](https://railway.app)
2. Нажмите **"Start a New Project"** или **"Login"**
3. Войдите через GitHub, Google или Email

### Шаг 3: Создание нового проекта

1. Нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"** (если ваш код на GitHub)
   - Или выберите **"Empty Project"** для ручного развертывания

### Шаг 4: Настройка переменных окружения

1. В панели проекта Railway нажмите на ваш сервис
2. Перейдите во вкладку **"Variables"**
3. Добавьте переменную окружения:
   - **Key:** `BOT_TOKEN`
   - **Value:** ваш токен Telegram бота (получите у @BotFather)

### Шаг 5: Настройка базы данных (опционально)

По умолчанию бот использует SQLite файл `bot_data.db`. На Railway файловая система эфемерная, поэтому данные могут теряться при перезапуске.

**Вариант 1: Использовать встроенную SQLite (для тестирования)**
- Ничего дополнительного делать не нужно
- ⚠️ Данные могут теряться при перезапуске

**Вариант 2: Использовать PostgreSQL (рекомендуется для продакшена)**
1. В проекте Railway нажмите **"+ New"** → **"Database"** → **"Add PostgreSQL"**
2. Railway автоматически создаст переменные окружения:
   - `DATABASE_URL` или `PGDATABASE`, `PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`
3. Обновите код для использования PostgreSQL (требуются изменения в `main.py`)

### Шаг 6: Настройка развертывания

1. В настройках сервиса убедитесь, что:
   - **Build Command:** (оставьте пустым или `pip install -r requirements.txt`)
   - **Start Command:** `python main.py` (уже указано в Procfile)

2. Railway автоматически определит Python проект по наличию `requirements.txt`

### Шаг 7: Развертывание

1. Если вы подключили GitHub репозиторий:
   - Railway автоматически развернет проект при каждом push
   - Или нажмите **"Deploy"** вручную

2. Если вы используете ручное развертывание:
   - Установите [Railway CLI](https://docs.railway.app/develop/cli):
     ```bash
     npm i -g @railway/cli
     railway login
     ```
   - В директории проекта выполните:
     ```bash
     railway init
     railway up
     ```

### Шаг 8: Проверка работы

1. В панели Railway перейдите во вкладку **"Deployments"**
2. Убедитесь, что развертывание успешно (зеленый статус)
3. Перейдите во вкладку **"Logs"** для просмотра логов
4. Откройте Telegram и найдите вашего бота
5. Отправьте команду `/start` для проверки работы

## 📝 Команды бота

- `/start` - Начать работу с ботом и увидеть список команд
- `/add_feed <url>` - Добавить RSS-ленту для подписки
  - Пример: `/add_feed https://habr.com/ru/rss/all/all/`
- `/list` - Показать все ваши подписки
- `/reading_list` - Показать список статей "Прочитать позже"

## 🔧 Настройка

### Переменные окружения

| Переменная | Описание | Обязательная | По умолчанию |
|------------|----------|--------------|--------------|
| `BOT_TOKEN` | Токен Telegram бота от @BotFather | ✅ Да | - |
| `DB_FILE` | Путь к файлу базы данных SQLite | ❌ Нет | `bot_data.db` |

### Интервал проверки лент

По умолчанию бот проверяет RSS-ленты каждые **10 минут**. Чтобы изменить интервал, отредактируйте строку в `main.py`:

```python
job_queue.run_repeating(check_feeds_job, interval=600, first=10)
```

Где `interval` - интервал в секундах (600 = 10 минут).

## 🐛 Решение проблем

### Бот не отвечает

1. Проверьте логи в Railway (вкладка **"Logs"**)
2. Убедитесь, что `BOT_TOKEN` установлен правильно
3. Проверьте, что бот не заблокирован в Telegram

### Ошибки при добавлении RSS-ленты

1. Убедитесь, что URL начинается с `http://` или `https://`
2. Проверьте, что RSS-лента доступна и валидна
3. Посмотрите логи для детальной информации об ошибке

### Данные теряются после перезапуска

- Это нормально при использовании SQLite на Railway (эфемерная файловая система)
- Для постоянного хранения данных используйте PostgreSQL (см. Шаг 5)

### Бот не отправляет новые статьи

1. Проверьте логи на наличие ошибок
2. Убедитесь, что подписка активна (команда `/list`)
3. Проверьте, что RSS-лента обновляется (откройте URL в браузере)
